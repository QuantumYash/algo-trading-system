# Algorithmic Trading System

A production-oriented algorithmic trading system implementing
live grid trading, stop-and-reverse logic, risk management,
technical indicators, macro regime detection, asynchronous
runtime components, order management, and backtesting.

## Features

- ATR-based grid strategy
- Stop-and-reverse
- Position limits
- Pyramiding
- Risk controls and kill switches
- Technical indicator engine
- Macro Regime Engine
- Async WebSocket processing
- Queue-based data pipeline
- Back-pressure handling
- Order management
- Restart/reconciliation logic
- P&L tracking
- Backtesting
- Slippage and transaction costs
- Walk-forward testing
- Unit and regression tests
